# Lifecycle: AskJamie

**Current status: Active**

AskJamie is a live, public-facing static site hosted at `https://askjamie.bot`.
The repository is in active development and maintenance.

## Status definitions

| Status | Meaning |
|--------|---------|
| Active | Under ongoing development; new content and features are added regularly |
| Maintenance | No new features; only bug fixes and dependency updates |
| Archived | Read-only; no further changes planned |
| Deprecated | Content is outdated; a successor or redirect exists |

## Transition rules

Before moving from Active to Maintenance:
- All open audit findings must be resolved
- Search index must be current
- QA checks must pass at 0 failures

Before archiving:
- Add a deprecation notice to `index.html`
- Set up a redirect or successor link at the canonical URL
- Update `robots.txt` to reflect reduced crawl priority if appropriate
