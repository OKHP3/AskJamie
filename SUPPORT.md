# Support

Thanks for using **AskJamie™**.

## How to get help

**Bug reports and questions** — open a [GitHub Issue](https://github.com/OKHP3/AskJamie/issues).
Please describe the page or file involved, what you expected, and what you observed.

**Direct contact** — email **contact@askjamie.bot** for anything not suited to a public issue,
including content concerns, broken links, or accessibility problems.

## What this repository covers

AskJamie is a static public website and brand artifact repository. Support for the following
topics is in scope:

- Rendering or layout problems on any public page
- Broken or misdirected links
- Accessibility or readability concerns
- Documentation clarifications for the Lens System or BrandGuard™ series

## Out of scope

This repository has no backend, database, authentication system, or form-processing service.
The following are therefore outside what can be addressed here:

- Account creation, login, or password issues
- API access or server-side integrations
- Data privacy requests unrelated to the public site content

For anything else, reach out at **contact@askjamie.bot** and the maintainer will route your
request appropriately.
