# AskJamie Replit project notes

`AGENTS.md` is the canonical project guide. This file records only the Replit
runtime and workflow configuration. Keep project facts here aligned with
`AGENTS.md`, and keep dated audit history in `assets/docs/`.

## Runtime

- Project type: static HTML, CSS, and JavaScript website.
- Public directory: repository root.
- Deployment target: static.
- Development server: `python3 -m http.server 5000 --bind 0.0.0.0`.
- Local port: 5000, exposed as port 80 by the Replit workflow.
- Nix modules: web, Node.js 20, and Python 3.11.
- No application build step is required.

## Current stack

- `assets/css/theme.css` is the single shared stylesheet.
- `assets/js/app.js` provides analytics bootstrap, search, navigation, theme
  behavior, reading progress, scroll behavior, and related shared browser work.
- `assets/js/mermaid-init.js` initializes Mermaid v11 for the Universe page.
- Google Fonts use Baloo 2, Open Sans, and Kalam for AskJamie pages.
- `assets/data/search-index.json` is generated by
  `scripts/build-search-index.py`.
- `package.json` declares Playwright as an optional development dependency for
  browser QA. Static QA works without Playwright.

## Replit workflows

The `Project` workflow starts the application, responsive QA, and site audit in
parallel. The individual workflows are:

```text
Start application: python3 -m http.server 5000 --bind 0.0.0.0
responsive-qa:      node scripts/responsive-qa.mjs --static
site-audit:         python3 scripts/audit-site.py --quiet
```

The post-merge hook is `scripts/post-merge.sh`. It verifies key files, rebuilds
the search index, and runs the canonical site audit. Review generated-file
changes before running it with other uncommitted work present.

## Replit-specific boundaries

- Keep browser-served files in the root and `assets/` structure described by
  `AGENTS.md`.
- Keep maintenance scripts in `scripts/`.
- Do not commit credentials or local Replit state.
- Do not treat the Replit workflow as proof that browser-level QA passed. The
  static responsive workflow does not test runtime overflow, console errors,
  external fonts, analytics, or image loading.
